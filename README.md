SakhiSarthi – Women's Safety Android Application

About the Project

SakhiSarthi is a women's safety Android application project designed to help users access emergency assistance quickly.

Key Features

- One-touch SOS activation
- GPS-based location tracking
- Emergency SMS alerts
- Emergency calling
- Emergency contact management

Technologies Used

- Java
- Android Studio
- Android Location APIs
- SharedPreferences
- Google Gson

Project Documentation

The project presentation is available in ""ppt.pdf"" (ppt.pdf).

Current Repository Status

This repository currently contains the project presentation. The Android application's source code will be added later.

Objective

To explore how mobile technology can support women's safety by making emergency assistance easier to access.
